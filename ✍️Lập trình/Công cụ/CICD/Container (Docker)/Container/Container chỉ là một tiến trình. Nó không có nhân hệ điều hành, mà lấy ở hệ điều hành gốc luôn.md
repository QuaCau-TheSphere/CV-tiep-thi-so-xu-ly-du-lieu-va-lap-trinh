[[Chương trình là một đoạn mã được lưu trên ổ đĩa. Tiến trình là khi đoạn mã đó được nạp vào RAM và được CPU đọc]]

Bởi vì lệnh liệt kê tất cả các tiến trình đang chạy trên shell là `ps`, nên lệnh để liệt kê tất cả các container đang chạy là `docker ps`.

Lệnh `docker ps` này tương đương với `docker container ls`. Để liệt kê tất cả các container bất kể có đang chạy hay không, dùng `docker ps -a`.
[[Nếu nhân hệ điều hành trong container khác với nhân hệ điều hành dùng để chạy Docker, thì phải chạy trên máy ảo]]
